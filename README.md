## Core Patterns

- **Movie Poster Auditor**: Movie Poster Invariant: keep the primary subject in the leading position across consecutive sentences to anchor reader focus.
- **Practical Application**: Technical tutorials, preventing disorienting attention jumping.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
